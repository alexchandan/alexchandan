## Featured Project

### Credify — Recruitment Platform

> A full-stack recruitment platform designed to provide candidates and recruiters with a secure, structured, and role-aware hiring experience.

Credify is one of my primary projects and a practical exploration of building a modern application beyond basic CRUD. The project focuses on **authentication, authorization, backend architecture, security, recruitment workflows, file handling, and production deployment**.

**Key engineering work:**

* Role-based experiences for **candidates, recruiters, and administrators**
* Secure authentication with **access tokens, refresh-token rotation, email verification, and password recovery**
* Authorization and policy layers for protecting application resources and actions
* Candidate, recruiter, company, job, and application domain modeling with MongoDB
* Resume upload and file-management workflows using cloud storage
* Request validation, structured error handling, rate limiting, security middleware, and application logging
* TypeScript-based frontend and backend architecture inside a pnpm workspace
* Production-oriented deployment with the frontend and API deployed independently

**Technology:**
`Next.js` · `React` · `TypeScript` · `Tailwind CSS` · `Node.js` · `Express.js` · `MongoDB` · `Mongoose` · `Zod` · `JWT` · `Cloudinary` · `Resend` · `Pino` · `pnpm`

**Repository:** [github.com/alexchandan/credify](https://github.com/alexchandan/credify)\
